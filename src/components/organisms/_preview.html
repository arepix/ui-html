Atributos por capa para iterar

  • font-family (sans/serif/mono)
  • font-size (text-[Nvw])
  • font-weight (font-light → font-black)
  • letter-spacing (tracking-*)
  • line-height (leading-*)
  • color (text-[var(--color-*)])
  • rotate (rotate-12, -rotate-6)
  • skew (skew-x-12)
  • opacity (opacity-50)
  • mix-blend-mode (mix-blend-screen)
  • text-transform (uppercase/lowercase)
  • font-style (italic)
