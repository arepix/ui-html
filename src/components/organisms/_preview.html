Familias de identidad

Separan la identidad visual (color, font, opacidad, casing) de la posición (preset).

data-typo

splatink, docallisme, street, mars, grafittiy, another, magik, cosinek, sear, 5cent

data-palette

negro, negro-claro, azul, verde, blanco, violeta

data-opacity

ghost (0.15), faint (0.4), mid (0.6), solid (0.9), full (1)

data-casing

upper, lower, none

Ejemplo de uso combinado

<span data-preset="grid-mid-16-9"
      data-typo="splatink"
      data-palette="negro-claro"
      data-opacity="solid"
      data-casing="upper"
      style="--x: 20%; --y: -15%; --size: 12cqi; --rot: 5deg">
  WILDFIRE
</span>

Sistema: canvas-split + layered-text-bg. Tokens: cqi para escala, data-preset para posición, data-typo/palette/opacity/casing para identidad. Reglas: sin style inline de identidad, solo variables de posición (--x, --y, --rot, --size, --op).
